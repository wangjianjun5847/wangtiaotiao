# 李跳跳自用去广告规则（wangtiaotiao）

基于 4 个社区规则源**全量合并**生成的自用规则集：**336 个 App、827 条规则**，覆盖开屏广告、弹窗广告、更新提醒、权限索取等干扰弹窗。格式与李跳跳官方规则完全一致，可直接导入。

李跳跳（LiTiaotiao）是一款 Android 跳过广告类应用（基于无障碍服务），官方已于 2023 年 8 月停更；本仓库规则来自仍在更新的社区规则源，会持续跟进。

## 文件说明

| 文件 | 说明 |
|---|---|
| `MyRules.json` | 规则主文件，**导入李跳跳用的就是这个** |
| `update_rules.py` | 更新脚本：拉取社区最新规则源，重新合并生成 `MyRules.json` |
| `README.md` | 本说明 |

## 导入方法（一次性）

1. 用手机浏览器打开本仓库的 `MyRules.json`（或下载后传到手机），全选复制
2. 打开李跳跳 → 更多 → 右上角三个点 → 导入规则
3. 长按输入框，选择系统粘贴，点保存
4. 回到李跳跳主界面，确认目标 App 在列表内且开关已打开

注意事项：

- 一次只能导入一个 JSON 文件，再导入其他文件会覆盖、不会合并——所以只导这一个文件
- 文件约 68KB，请用手机浏览器直接打开复制；不要经微信、输入法等第三方 App 中转，可能被截断
- App 卸载重装后规则仍然生效，不需要重复导入

## 更新规则

规则库是"活"的：社区规则源仍在更新，App 升级后老规则可能个别失效。两种更新方式任选：

**方式 A：让我更新（推荐）**
直接对我说"更新一下李跳跳规则"，我会重新拉取社区规则源、合并、生成新版 `MyRules.json`，推送仓库并告诉你具体改了什么，你再把新文件导入手机即可。也可以让我设置成定期自动更新（当前已设为每两周一次，有变化时自动推送）。

**方式 B：自己更新**
电脑上安装 Python 3.8+ 和 git 后，在本目录执行：

```bash
python update_rules.py
```

脚本会自动完成：拉取 4 个社区规则源 + 官方应用名录 → 按包名 hashCode 匹配 → 全量去重合并 → 与旧版对比输出变更报告 → 重新生成 `MyRules.json`。

想改回"只收录常用 App"模式：打开 `update_rules.py`，把 `SCOPE = "all"` 改成 `SCOPE = "target"`，脚本就只合并内置的 36 个常用 App 清单。
